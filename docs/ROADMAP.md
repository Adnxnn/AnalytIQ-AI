# AnalytIQ AI — Development plan

## M0 — Repository and preview
Next.js landing and workspace shell; GitHub and Vercel configured. No customer file ingestion until API authentication is in place.

## M1 — Secure analytics
Supabase auth, RLS-scoped projects, immutable originals in private buckets, authenticated analytics API, dataset profiling and deterministic calculations, saved analysis, validation and exports.

## M2 — Intelligent analytics
Structured planner and orchestrator, tool allowlists, retries, usage controls, reproducible execution manifests, trustworthy analytical narratives, pivots and formula studio.

## M3 — Universal file adapters
Capability registry, XLS/XLSB/ODS/Parquet/JSON, PPTX/PDF/DOCX/image extraction with explicit OCR uncertainty and source provenance. Safe ZIP extraction and content constraints.

## M4 — Assessments and artifacts
Assessment solver, editable Excel formulas, charts and report generation, PowerPoint theme-aware edits, PDF/DOCX technical handovers and reconciliation.

## Release gate
No production claim without build, auth, multi-tenant isolation, end-to-end tests, scanning, audit and retention validation.
